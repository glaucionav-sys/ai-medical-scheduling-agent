# Como publicar no GitHub

## Nome recomendado do repositório

`ai-medical-scheduling-agent`

## Descrição

`Production-inspired n8n AI agent for medical scheduling, patient service, CRM integration and human handoff.`

## Visibilidade

Use `Public`.

## Upload pelo navegador

1. Crie um repositório vazio no GitHub.
2. Não precisa adicionar README, `.gitignore` ou license na criação; eles já estão no pacote.
3. Extraia o ZIP deste projeto no seu computador.
4. Na página do repositório, clique em **Add file > Upload files**.
5. Arraste a pasta/conteúdo do projeto para a área de upload.
6. Confira se `README.md` ficou na raiz do repositório.
7. Use a mensagem de commit:
   `Add sanitized AI medical scheduling portfolio project`
8. Faça o commit.
9. Abra a página inicial do repositório e confira se o README foi renderizado corretamente.

## Depois dos screenshots

Adicione as imagens em `docs/screenshots/` com os nomes definidos em
`docs/SCREENSHOT_GUIDE.md`.

Nunca suba o JSON original de produção.
